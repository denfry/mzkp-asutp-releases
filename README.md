# Диспетчерская МУЖКП — установщики

Здесь только готовые установщики приложения для Windows. Отсюда же приложение само скачивает обновления.

Установить: в разделе [Releases](https://github.com/denfry/mzkp-asutp-releases/releases/latest) скачать
`mzkp-dispatch-setup-<версия>.exe` и запустить. При первом запуске выбрать «Подключиться к серверу»
и войти через телеграм-бота диспетчерской. Доступ открывает владелец.
